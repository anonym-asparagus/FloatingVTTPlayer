# Frontend reference, version 1

The image `frontend-reference-v1.png` is an original concept for the macOS app.
It is a visual reference, so the extra example tracks and wallpaper are illustrative.
The implemented player only shows files loaded from the selected local folder.

Design direction: a dark, compact listening workspace with a narrow folder and
subtitle-controls rail, a prominent Now Playing area, a track queue, a persistent
transport bar, and a separate floating subtitle window.

The reference was generated with the built-in image generation tool using this
prompt:

> Design a modern music-player-inspired interface for a local WAV/MP3 and VTT
> subtitle player named Floating VTT Player. Original visual design, not a
> copy of an existing product. Show a macOS player window with a compact
> library rail, Now Playing area with abstract waveform artwork and current
> subtitle, a slim local-file queue, persistent playback controls, and a
> separate floating subtitle overlay with pause, lock, Aa, close, and resize
> controls. Use a graphite-dark palette, restrained lavender accent, clear
> typography, generous spacing, and obvious click targets. No streaming,
> podcasts, recommendations, or other unsupported features.

Design research:

- [Spotify desktop redesign](https://newsroom.spotify.com/2023-06-20/spotify-desktop-experience-redesign-your-library-now-playing-views-customize/): distinct library and Now Playing areas.
- [Apple Music on Mac](https://support.apple.com/guide/music/customize-the-music-window-mus0cec331d6/mac): native Mac window controls and customizable listening space.
- [Plexamp](https://www.plex.tv/plexamp/): focused music-player presentation.
